# aramkoukia.github.io

Personal blog built with Jekyll and hosted on GitHub Pages.

## Write a new post
Create `_posts/YYYY-MM-DD-my-title.md`:

    ---
    layout: post
    title: "My title"
    date: 2026-10-19
    ---
    Content in Markdown.

## Preview locally (optional)
    bundle install
    bundle exec jekyll serve
