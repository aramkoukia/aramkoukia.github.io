### Microsoft Visual Studio 2017 is here!

![](https://cdn-images-1.medium.com/max/1200/1*kxtvvzVygoK_KHxyhrjtrg.jpeg)

### Today Visual Studio 2017 is lunched.

Several great features to be excited about. First and the most interesting one, is the fixes to the .csproj files and now they are definitely more readable!

![](https://cdn-images-1.medium.com/max/800/1*AwhArRfj0SCMPu-ZLB6eOQ.png)

Yeah, no jokes, this above picture is how a .csproj file looks like now! No wonder a solution would load much faster, eh?

**From** [**release notes**](https://www.visualstudio.com/en-us/news/releasenotes/vs2017-relnotes)**:**

> Visual Studio has been optimized to reduce startup time and solution load time. The very first launch of Visual Studio is at **least 50% faster**.

Also, live unit testing! though it is not available in the “Community Edition” and is just in the Enterprise license, which is a bummer!

Aaaand finally, the support for “Open Folder” is here, so you don’t need a .csproj or .sln file to open a bunch of classed! Awesome!

![](https://cdn-images-1.medium.com/max/1200/1*4ZVUxOg9YedU7fFnOhJRKQ.png)

And of course the support for C# 7.0 language features.
