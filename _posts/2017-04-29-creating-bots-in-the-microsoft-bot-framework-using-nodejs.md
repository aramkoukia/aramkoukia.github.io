### Creating Bots in the Microsoft Bot Framework using Node.js

![](https://cdn-images-1.medium.com/max/800/1*6yzfhTg325gMPzPNGZuqNA.jpeg)

I came across this great Microsoft Bot Introduction Course a while ago and thought to share it with you.

Here is the course content:

1 | Getting Started with the Bot Framework

Before building your first bot, learn what bots and Microsoft Bot Framework can offer, in addition to how best to design a bot.

2 | Hello Bots

Learn how to get started creating a bot using Node.js, and find out how building a bot is similar to building any application.

3 | Bot Workflow

Learn how, when building a bot, you need to guide the user through a set of questions to collect the needed information to either provide the correct answer or perform an action on the user’s behalf.

4 | Interacting with the User

Learn about many ways of communicating with the user, beyond just text, that Microsoft Bot Framework includes. Send rich information through the use of cards, or use buttons to help guide the user.

5 | Natural Language Processing with LUIS

Get the details on using LUIS to handle natural language processing. One of the goals of bots is to allow the user to interact with it in much the same way they’d interact with a human.

6 | Deploying Your Bot

After you’ve built your bot, it’s time to publish it to the world, allowing people to interact with it. See how to deploy the logic, register your bot, and add it to Skype.
