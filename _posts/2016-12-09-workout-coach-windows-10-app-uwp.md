### Workout Coach — Windows 10 App — UWP

I have been playing with XAML and Universal Windows Platform App development and as part of this experiment I published the App too to see the experience end to end.

One app that I build is the Workout Coach which I build using UWP Targeting Windows 10.

The App is about Workout and it targets ARM, x86 and x64 CPUs.

I have put some predefined workout routines that users can use as well as the feature that you can add your own workout routines there.

It has some speech features like it will count down when a workout step is about to finish and it says the workout step out load when you have to switch to a different workout step.

And I added some setting to disable the speech if you found it annoying. Also you can delete the workouts if you want.

I’m thinking of adding some features like: Bing Search API to lookup the workout step and show it to the user. And I want to enable the APP to use Cortana for that.

Like when a workout step is running, the user can say: “Show me”, then the App will understand that, goes to Bing and finds a picture or a clip of that step and shows it to the user.

I’ll submit that as a new version to the Windows Store.It keeps the data as xml files on the device and everything works offline as of the first version.
