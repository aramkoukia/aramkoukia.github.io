### How to Add #Azure Application Insights telemetry to an existing .Net Core Application

![](https://cdn-images-1.medium.com/max/1200/1*6QA1hZ8uE4GTaz8rIzUdzg.png)

In this video I demonstrate, how to setup Azure Application Insights telemetry in an existing .Net Core Application that does not have any telemetry setup.

- Add the required Nuget packages for Application Insights.
- Create the Application Insights instance in Azure.
- Take a look at the Application Insights that was created in Azure portal.
- Look at some of the configurations that was added to point your application to the Application Insights instance in Azure.
