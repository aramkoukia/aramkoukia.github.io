### VSTS is dead, long live Azure DevOps

![](https://cdn-images-1.medium.com/max/1200/1*ufz1-ED69SSID21w1TCnRg.jpeg)*Plan smarter, collaborate better, and ship faster with a set of modern dev services. Image from: <https://azure.microsoft.com/en-us/services/devops/>*

Starting today, if you use Azure you will get DevOps, whether you want it or not!

In the past few years everyone has been talking about DevOps and how important it is for every successful software team to have proper DevOps solutions.

But before today, people who used Azure, they needed to plan for their own DevOps pipeline for CI/CD, source code repository, work item management and test management, but today Azure announced that you can build all your DevOps process in Azure.

Here are some of the stuff that you can do with Azure DevOps:

- A CI/CD pipeline that works with any language, platform, and cloud.

[**Azure Pipelines | Microsoft Azure**  
*Get 10 free parallel jobs for cloud-based CI/CD pipelines for Linux, macOS, and Windows. Automate builds and easily…*azure.microsoft.com](https://azure.microsoft.com/en-us/services/devops/pipelines/ "https://azure.microsoft.com/en-us/services/devops/pipelines/")

- A powerful work tracking system with Kanban boards, backlogs, team dashboards, and custom reporting and more

[**Azure Boards | Microsoft Azure**  
*Track your software projects and plan better with agile tools, including scrum boards, Kanban boards, and dashboards…*azure.microsoft.com](https://azure.microsoft.com/en-us/services/devops/boards/ "https://azure.microsoft.com/en-us/services/devops/boards/")

- Artifact management with Maven, npm, and NuGet package feeds from public and private sources.

[**Azure Artifacts | Microsoft Azure**  
*Create Maven, npm, and NuGet package feeds from public and private sources with Azure Artifacts. Share code, get…*azure.microsoft.com](https://azure.microsoft.com/en-us/services/devops/artifacts/ "https://azure.microsoft.com/en-us/services/devops/artifacts/")

- Unlimited cloud hosted GIT source code repository for your public and private repos.

[**Azure Repos - Git Repositories | Microsoft Azure**  
*Get free private Git repositories and code collaboration in the cloud. Create Git pull requests and review code with…*azure.microsoft.com](https://azure.microsoft.com/en-us/services/devops/repos/ "https://azure.microsoft.com/en-us/services/devops/repos/")

- A test plans suite for you to document, manage, and run all your test suites and test plans.

[**Azure Test Plans | Microsoft Azure**  
*Test and ship software with manual and exploratory testing tools from Azure Test Plans, formerly on Visual Studio Team…*azure.microsoft.com](https://azure.microsoft.com/en-us/services/devops/test-plans/ "https://azure.microsoft.com/en-us/services/devops/test-plans/")

All of the above features are open and fully extensible and they work with any platform or technology stack that you may use (Not just Microsoft folks!)

### Good news for Open Source projects

Azure offers free CI/CD pipelines with unlimited minutes for build and releases with maximum 10 parallel jobs.

> Many of the top open source projects are already using Azure Pipelines for CI/CD, such as [Atom](https://dev.azure.com/github/Atom/_build/results?buildId=6092&view=logs), [Cpython](https://dev.azure.com/python/cpython/_build/results?buildId=24985&view=logs), [Pipenv](https://dev.azure.com/pypa/pipenv/_build/results?buildId=719&view=logs), [Tox](https://dev.azure.com/toxdev/tox/_build/results?buildId=355&view=logs), [Visual Studio Code](https://dev.azure.com/vscode/VSCode/_build/results?buildId=6174&view=logs), and [TypeScript](https://dev.azure.com/typescript/TypeScript/_build/results?buildId=11132&view=logs) — and the list is growing every day.
