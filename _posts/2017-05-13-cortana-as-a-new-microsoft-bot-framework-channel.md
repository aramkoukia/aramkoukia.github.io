### Cortana, as a new Microsoft Bot Framework Channel

![](https://cdn-images-1.medium.com/max/2560/1*__HfdCfmG9Y8Z3JMi-Jg8g.jpeg)

In Build 2017, Microsoft announced [several updates](https://channel9.msdn.com/events/Build/2017/B8097) to the Bot Framework which are great, and as I was expecting, this great bot framework is here to stay!

One of the features that made me really excited, and something that will push me to think about bot use-cases even more, is the Cortana channel.

Why is this important? because it makes your bot much more accessible and easier to discover, more than ever.

With Cortana channel:

> your Bot will be right there in front of [**400 million users, in 192 countries**](https://news.microsoft.com/bythenumbers/windows-ten) that use Windows 10!

The **Cortana channel** enables us to extend Cortana by adding skills to it.

*Check out the* [*Cortana developer portal*](http://developer.microsoft.com/Cortana) *to see how to you can add your specific skills to Cortana.*

![](https://cdn-images-1.medium.com/max/1200/1*XRcXueq2ROXIXtD_aV34ew.png)

Cortana skills can be is extended, that means, we can build bots using the bot framework, and publish them as Cortana’s new skills. Using the Bot Framework, we can develop, debug, release bots that users can access via the Cortana Channel from their Windows 10 devices without any other application needed.

![](https://cdn-images-1.medium.com/max/1200/1*FdKbsV6lvCGVZfLjyXkCKQ.png)

All it takes to add your existing bots to Cortana is to add a new channel, test to make sure your code works well on a speech-first canvas, and then publishing the bot to the Cortana Channel!
