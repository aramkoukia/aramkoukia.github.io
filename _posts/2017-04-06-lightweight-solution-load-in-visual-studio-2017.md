### Lightweight Solution Load in Visual Studio 2017

![](https://cdn-images-1.medium.com/max/2560/1*tysHeq88_zDpPYvsv5ZDJQ.jpeg)

Visual Studio 2017 has lots of cool features, but there is one feature there that has not got a lot of traction, and it a really good one specially for people that work with solutions with over 20 projects.

#### It is called: Lightweight Solution Load.

(I just recalled one president used to call some women “Lightweight” in his speeches. Just wanted to clarify this is a different kind of lightweight!)

Even though, Visual Studio 2017 project structures and performance is much better than older versions, it will still be slow when your solution has like 200 projects in it and that’s where this feature comes in handy.

### Enable Lightweight Solution Load for a specific solution:

To enable this feature in a specific solution, just right click on the solution and choose: “Enable Lightweight Solution Load” like the following picture:

![](https://cdn-images-1.medium.com/max/800/1*lfaxJrJG0oBgEsU5LhVs5Q.png)*Enabling Lightweight Solution Load in Visual Studio 2017*

### Enable Lightweight Solution Load for all solutions:

To enable this feature in all your solutions, go to *Tools > Options* menu just like the following picture:

![](https://cdn-images-1.medium.com/max/800/1*c6mj8Jupb1JzBblTfCoszg.png)*Enabling Lightweight Solution Load in Visual Studio 2017 for All Solutions*

Hope this saves you some time.

Cheers!
